# Chattr - Real Time Chat Application

A sleek, modern real-time chat application built with the **MERN** stack and **Socket.IO**, optimized for both performance and visual appeal.

![Chattr Preview](./public/sample.jpg)

[Live Demo](https://chattr-chat.vercel.app)

---

## Features

- **Real-time Messaging**: Instant message delivery with WebSocket connections via Socket.IO
- **Modern UI/UX**: Clean, intuitive interface designed in Figma with attention to visual details
- **Message Persistence**: Messages stored in MongoDB for data persistence
- **Sender Differentiation**: Messages automatically aligned based on sender with proper timestamp positioning
- **Real-time Updates**: Live message updates without page refresh
- **Cross-platform**: Deployed on Vercel for both frontend and backend

---

## 🛠️ Tech Stack

- **Frontend**: React, Tailwind CSS
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Real-time Communication**: Socket.IO
- **Deployment**: Vercel

---

## 💡 Key Implementation Details

- **Real-time Communication**: Implemented with Socket.IO for instant messaging
